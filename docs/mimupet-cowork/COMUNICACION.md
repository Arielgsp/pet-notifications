# MimuPet — canal Cowork ↔ Code

Desde el 05/11/2026 Cowork trabaja sobre esta misma carpeta. Nos comunicamos por archivos, sin que Ariel tenga que copiar y pegar.

## Dónde va cada cosa

| Carpeta o archivo | Quién escribe | Quién lee |
| --- | --- | --- |
| `docs/mimupet-cowork/LEEME-traspaso.md` | Cowork: **estado vigente del proyecto** | Los dos |
| `docs/mimupet-cowork/para-code/` | Cowork: pedidos, diseños, textos, respuestas (su LEEME dice cuáles siguen vigentes) | Code |
| `docs/mimupet-cowork/para-cowork/` | Code: informes, preguntas, decisiones pendientes | Cowork |
| `docs/mimupet-cowork/anteriores/` | Cualquiera: lo reemplazado | — |
| `docs/PENDIENTES.md` y `docs/PRUEBAS.md` | Code (como siempre) | Los dos |

## Reglas

- Un archivo por tema, con fecha al principio del nombre: `2026-11-05-icono.md`.
- Al terminar un pedido, Code anota al final del archivo `Estado: hecho en 1.0.xx` (o la duda), y no lo borra.
- Lo que necesita a Ariel (precios, cuentas, decisiones) va marcado **Para Ariel**.
- Cowork no toca código ni `PENDIENTES.md`; Code no toca los documentos de tienda, prensa ni redes.
- Si dos documentos se contradicen, manda el más nuevo; ante la duda, `LEEME-traspaso.md`.
