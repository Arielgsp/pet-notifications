# Plaquita

Una etiqueta de papel colgada del collar con un hilito, con título y hora; para rutinas cortas y repetidas.

**Recibe:** nombre de la mascota, hora, título corto (hasta ~18 caracteres). Al tocar: cuerpo y 1–2 acciones.

- Fondo `paper`, borde `line`, `radius-sm`, `shadow-lift`, relleno `space-3`; ojal con aro `sage`; hilo en `fur`, del ojal al collar.
- Al llegar se balancea dos veces sobre el ojal (±3°, 3,2 s) y queda quieta.
- Al tocar, crece hasta mostrar cuerpo y acciones.

**Sí:** "Tomar agua", "Estirar", "Pastilla de las 22". **No:** textos largos ni avisos Importantes: no hay lugar para la palabra y el ícono.

**Esfuerzo:** bajo. Es una vista con rotación; el hilo se dibuja entre dos puntos.
